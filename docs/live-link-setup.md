# Live Link Setup

This stage prepares the repository for production deployment. The public URLs are created from the hosting dashboards after GitHub is connected.

## Backend: Render

1. Open Render and create a new Blueprint.
2. Connect `https://github.com/sridharmekala/SMARTED-AI-Learning-Platform`.
3. Select the root `render.yaml`.
4. Add the required secret environment variables:

```bash
DB_HOST=host
DB_PORT=3306
DB_NAME=database-name
DB_USE_SSL=true
DB_USERNAME=database-user
DB_PASSWORD=database-password
NVIDIA_API_KEY=nvapi-your-key
```

5. Remove any old `DB_URL` variable from Render if it exists.
6. Keep `JWT_SECRET` generated by Render or replace it with a strong secret.
7. Deploy and verify:

```text
https://your-backend-domain.onrender.com/health
```

Expected response:

```text
OK
```

## Frontend: Vercel

1. Import the same GitHub repository in Vercel.
2. Set the project root directory to `frontend`.
3. Use the default Vite settings:

```text
Build command: npm run build
Output directory: dist
```

4. Set the frontend environment variable:

```bash
VITE_API_BASE_URL=https://your-backend-domain.onrender.com
```

5. Deploy and copy the Vercel domain.
6. Update the Render backend environment variable:

```bash
CORS_ALLOWED_ORIGIN_PATTERNS=https://your-frontend-domain.vercel.app
```

7. Redeploy the backend after changing CORS.

## Final Verification

- Backend `/health` returns `OK`.
- Student register and login work from the deployed frontend.
- Admin login reaches the admin dashboard.
- AI tutor responds when `NVIDIA_API_KEY` is configured.
- Screenshots are refreshed after the live UI is stable.
